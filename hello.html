Purpose

This server is not designed for production use. It exists to understand how web servers work at a low level using Rust’s systems programming model.

Design Choices

HTTP parsing, TCP handling, and a thread pool are implemented manually. Async/await is intentionally avoided to keep the focus on concurrency fundamentals.

Key Learnings

Ownership in concurrent code, safe multi-threading, request dispatching via a worker pool, and how abstractions used by modern frameworks are built underneath.
